## A tutorial of Github and Markdown
This lab is a tutorial on all the important fundementals to file management and digital notekeeping.

It covers the basics of Markdown, an HTML based language that helps create documents, and Github, a popular file management system.
It starts with a tutorial on how to use markdown, and lets us experiment in many different ways how to document things.
Then, it moves on to using Github to store this lab log alongside a weekly log that we will use to record everything done in this project.

### Steps to take:

1. Read the instructions from Canvas
2. Create lab1_overview.md
3. Create a file to store the Github Repository
4. Log into Github desktop, and create a new repository
5. Create README.md, the weekly project log folder, and the week 1 project log
6. Update the week 1 project log and write a description for README
7. Create a screenshot of the email
8. Commit and push the changes onto Github
9. Make some last edits and revisions
10. Submit the assignment
